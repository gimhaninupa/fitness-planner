# 🏋️ FitUnique - Your Personalized Fitness Planner

## 📖 About The Project
A personalized and feature-rich fitness tracking application built with Flutter. Designed to help you create, manage, and track your workout routines, monitor weight progress, and manage daily health goals (like hydration). The app emphasizes a clean, responsive interface with robust local data management.

## ✨ Key Features

* **User Profiles:** - Create and manage personal fitness goals (Lose, Gain, Maintain), age, height, and current weight.
* **Workout Planner:** - Build reusable workout routines containing multiple exercises with specified sets, reps, and rest times.
* **Session Tracking:** - Simulate starting a workout session, tracking exercises, sets, and rest periods.
* **Progress Monitoring:** - Log weight entries over time and view simple progress charts.
* **Water Tracking:** - Simple counter for tracking daily water intake (cups).
* **Theming:** - Supports light mode and a custom dark mode with a cohesive color scheme.
* **Data Persistence:** - Uses shared_preferences to save user profiles, logs, and workouts locally.

---

## 🛠️ Technologies Used

* **Framework** - Flutter.
* **Language** - Dart.
* **State Management** - provider.
* **Local Storage** - shared_preferences.
* **Utilities** - intl (for date formatting)..
